# 固件工件

[English](firmware.md)

[`firmware/`](../firmware/) 包含用于烧录和恢复的已发布出厂镜像。它是不可变交付物：日常文档和 CI 工作不得重新构建、重新打包、重命名或修改该文件。

示例工作流仅构建 `examples/` 下的第一方工程，并可能打包源码构建诊断工件。这些工件不是出厂固件，也不验证或替代出厂固件。其他固件表面的源码和构建说明尚未包含在此处，后续更新可能会提供。

[发布辅助工具](../releases/README_ZH.md)会从构建输出创建逐示例归档，也可以下载指定 GitHub Actions 运行的工件。它们只写入配置的输出目录，绝不会更新仓库中的出厂镜像。
